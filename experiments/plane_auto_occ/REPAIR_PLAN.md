## 2. 采样：每层32768点，增加数量并改变空间覆盖

### 2.1 每层每步的配额

| 区域 | 个数 | Binary标签 |
| --- | ---: | ---: |
| 心肌 | 16384 | 1 |
| 心腔 | 8192 | 0 |
| 背景 | 8192 | 0 |

删除固定3mm near/far分层。near/far仅保留为审计统计，不参与配额或损失权重。

区域平衡是刻意定义的训练目标；这些点上的Dice不等于整幅区域的面积Dice。正式修正版同时提高点数并修正分布。仅增加旧小池的重复抽样次数不会增加独立空间覆盖。

### 2.2 正式采样池如何建立

仅选中的观测平面可以提供训练标签。先锁定 observed=0,3,6，再建立训练ROI和点池，不能先用隐藏平面扩大ROI或定义统计量。

使用观测轮廓在共同平面基底中的联合包围盒，四周加20mm作为训练域。这是为扩大背景覆盖选定的工程初值；主评估继续使用原+5mm域，另加+20mm鲁棒性审计。各平面映射回同一个原始归一化3D坐标系，q@axis=s_i，center_mm/scale_mm不变。

在该域内均匀提出连续2D坐标，用已有 Epi/Endo 多边形判定：
- Epi内且Endo外：心肌。
- Endo内：心腔。
- Epi外：背景。

这是在真实观测平面内重采样，不给层间3D查询点制造GT。标签是已有轮廓的填充代理，应保持该评估口径；若采用MRI raster，需要另立协议。

按类别接受均匀候选，建立独立随机池，建议心肌131072、心腔65536、背景65536个有效点/观测层，总计262144个；这是每步32768点的8倍。数量是容量初值，不是沿用旧非均匀池的索引。点池坐标、随机种子、原轮廓哈希、ROI和类别审计写入新缓存，原缓存保留。

只忽略距边界<=0.05mm的数值模糊带；轮廓本身不被解释为心肌正样本。严格检查Endo在Epi内、每个区域有足够的有效空间。采样失败应报出具体平面和池大小，不能把小池静默重复扩充。

区域内使用随机排列、连续消耗的方式抽取；每步无放回，跨步覆盖完整池后再洗牌。使用上述整倍数池大小，各类别每8步完成一轮。为减少对固定坐标的记忆，建议每完成10轮覆盖后用新的均匀候选重建池；该间隔仍是可调整工程参数。所有重建只读取观测轮廓。

### 2.3 最小采样消融与正式方案的区别

为确认旧far配额的作用，可额外做一次保持旧1024点/层预算的最小消融：只在旧缓存每类全部有效点中无放回抽样，其他项保持V1不变。第6层三个far点在512个正样本中的期望出现数为512*3/3249=0.473，而不是每步256次。

这个对照能消除far点放大，但旧缓存仍含Gaussian等非均匀空间密度。“对旧索引均匀抽样”不等于“按区域面积均匀采样”；正式修正版采用2.2的新池。

### 2.4 必须记录

每层、每类别的池大小、当步独立点数、重复率、near/far计数、跨步池覆盖率、心肌/心腔/背景正确率。第6层三个旧far点可以作为诊断探针，不能在新池中享有固定配额。

### 2.5 与参考论文对齐的数量口径（17:29补充）

作者博士论文附录转载了2024正式论文全文。其第4.3节（原论文第5页，合订PDF零基第90页）明确：训练batch为8个volume，每个epoch为batch中的每个稀疏训练shape随机选择64³=262144个监督voxel；新shape重建时，每个梯度更新使用全部可用稀疏输入voxel。64³不是输出mesh网格或纯离线候选池。应进一步通过源代码核对任何特定实现中的replacement/chunk策略，不能假定全部为互异坐标。

| 数量口径 | 原V1（三层） | 当前修正版（三层） |
| --- | ---: | ---: |
| 每层每次更新的监督点 | 1024 | 32768 |
| 每病例每次更新的独立输入坐标 | 3072 | 98304 |
| 每观测层离线池 | 旧池，密度不均匀 | 262144 |
| 三个观测层总离线池 | 依原缓存 | 786432 |

不把论文8个病例的batch总点数2097152与本次单病例预算混为一谈；其epoch也不等于本代码全训练集只做一次optimizer更新。原V1每个病例更新包含所有3个观测层，1024的单位是每层。

32k/层是参考文献量级与当前三层设置共同决定的工程预算，不是已验证最优点数，也不是普遍的Auto-Decoder最低要求。连续重采样提高loss积分与梯度估计的空间覆盖，不会增加原始轮廓的独立解剖信息或影像分辨率。点只来自可观测平面，间隙仍没有GT。

### 2.6 显存：4096点分块，累计一次完整病例更新

每层32768点拆为8个4096点块；每块保持心肌2048、心腔1024、背景1024。病例的三个平面全部累计完后才做一次optimizer.step，不能把每块记为一个完整更新。

每块的mean BCE乘以4096/32768=1/8，再乘该层的1/N和Direct/LOO混合系数。每层8块合计恰好恢复第3节目标。Direct与LOO复用坐标，因此三层98,304是独立输入数；LOO开启时另有中间层32,768次decoder查询，不将它们计成新独立点。

实现顺序：zero_grad一次 -> 逐层逐块forward/backward -> case正则只计算/backward一次 -> 完整梯度记录与裁剪一次 -> optimizer.step一次。不得在每块之后更新或裁剪。为避免反复backward同一generator计算图，每块重新计算该块所需plane latent/LOO latent；生成器开销远小于大量点的decoder开销。当前网络无BatchNorm和Dropout，分块计算不引入这两类批依赖。

点池可以放CPU，只传活跃块至GPU。计算成本仍随总查询数量增长，分块主要控制峰值显存，不将其描述为免费扩容。记录峰值显存、病例更新耗时、累计独立点数及decoder查询次数；修正版与V1比较时同时说明32倍点预算差异。

## 3. Loss：每层的监督总权重相同

定义 D_i 为第i个观测层Direct BCE，O_i为内部层的邻居latent插值BCE。二者各自使用同样的16384/8192/8192区域配额。

区域损失显式写为：

    D_i = 0.5 * BCE_mean(myocardium)
        + 0.25 * BCE_mean(cavity)
        + 0.25 * BCE_mean(background)

O_i同式。Direct和LOO使用相同采样点，使差异来自latent路径，而不是两个随机批次。保持binary_cross_entropy_with_logits；logit>=0为预测心肌。

每层损失：

    endpoint: ell_i = D_i
    interior: ell_i = (1-beta) * D_i + beta * O_i

总目标：

    L = 1.5 * mean_i(ell_i) + lambda_mean * mean(z_case**2)

固定 beta=0.25，从第一步启用；lambda_mean=1e-4，Seam权重保持0。外层1.5来自旧数据损失权重0.5+1.0，使本轮调整层间权重时保留总数据项系数，不另行改变整体loss尺度。

三层情况下，当O_1≈D_1时：

    L_data ≈ 0.5 * (D_0 + D_1 + D_2)

计入外层1.5，中间层Direct系数0.375、LOO系数0.125，合计0.5；端点也各0.5，消除7:1失衡。这里采用预算分配而非把LOO额外叠加。原来的0.5*mean(Direct)+mean(LOO)配置应退役，并通过新目标版本标识避免读错。

同样的128维正则，若改写sum(z**2)，等价系数应为1e-4/128=7.8125e-7。不能在未说明尺度变化时直接使用相同系数，也不能为了让正则loss数字变大就盲目增加权重。正则不是迫使code承担病例信息的工具。

## 5. 网络和case code的处理

本轮主实现保持：
- case code 128D。
- generator输入[case code, physical-height-coordinate, phase]，原MLP结构。
- 128D plane latent。
- 按真实层间距离进行latent插值。
- 原宽256、五Linear、四Softplus和拼接skip的单头occupancy decoder。
- 同一坐标规范、无轴向外推。

不以相邻latent不相同、plane latent置零敏感或LOO≈Direct证明病例编码有效。generator近乎仿射不一定错误，健康的形状变化本身也可能较平滑；不增加“强制latent弯曲”或方向均匀正则。

单病例目标只要求观测拟合和插值行为可运行。code在该模式下信息可以被共享权重吸收；用人为推远codes、给其加范数下界或随机改变phase来制造差异，没有形状质量依据。

先通过单病例门槛，再按固定8:1:1、患者级隔离进行多病例共享网络训练，各case/phase有独立code。测试新患者时冻结generator/decoder，只优化新code。此时如果无法拟合观测，才说明共享先验/条件接口仍存在问题。ED/ES不得跨患者划分泄漏。

诊断至少包含：真正case code置零、替换为另一个病例code、随机code重复对照、plane latent置零；同时报告logit差与统一网格变化。新病例code相较固定初始code的观测拟合改善，是有用性检验的一部分，不能只看code间距离。

## 6. LOO的准确含义与真正留层测试

当前LOO准确称“邻居latent插值一致性监督”。其目标层GT仍参与训练，并更新共享参数和case code。

真正留层检验应使用独立协议：冻结由其他训练患者学到的共享网络，重新初始化测试病例code，仅从保留平面优化code；被留出的平面不参与目标、门控、ROI或选checkpoint，然后评估它。每个留层折重新初始化code和其优化器，不能沿用看过该层标签的病例code。

单病例联合训练模式的严格留层测试，要为每一折从头训练网络及code，整个训练过程中完全排除该层。其结果仍不构成跨病例先验评估。

## 8. 验收及失败定位

### 8.1 第一关：观测拟合

本轮训练后暂定工程验收：三个有效完整环形观测层分别Dice>=0.90，预期Epi/Endo边界闭合，没有侧向触边。这是事后结果检查，不触发训练阶段或改变基线的checkpoint选择。最终结果同时列出各层心肌召回率、心腔/背景误报率，避免仅看均值遮蔽第6层。

统一评估主域仍为原+5mm、160x160、logit=0；附+20mm裁剪审计。Dice属于cached-contour proxy。输出128³ mesh，区分轴向截断边与侧向异常边，不用封盖或增大分辨率掩盖错误。

### 8.2 LOO的独立诊断

正式运行从第一步使用固定beta，无LOO开启阶段。若需要判断一致性项作用，另外运行同seed/2000更新的修正采样Direct-only对照；它是单独实验，不是正式方法warmup。不能调隐藏层阈值获得更好指标。

### 8.3 第三关：隐藏层补全

固定最终模型及阈值后评估全部严格隐藏层，报告逐层Dice、闭合曲线、触边、必要时轮廓距离。观测层成功是必要条件，但稀疏平行切片并不唯一决定间隙形状，不能保证观测拟合好就必然补全好。

### 8.4 Direct仍失败时的有限定位

依次定位，每次只改变一项：
1. 抽样可视化覆盖与区域标签检查，验证新均匀池确实覆盖整个环及心腔/背景。
2. 固定一个常量latent，使用同一个decoder只拟合单个观测平面，从监督与decoder中剥离generator；这是诊断，不替换正式主方法。
3. 该诊断失败：另立下一阶段实验，检查坐标范围与decoder表达能力。任何学习率或坐标变更都需要单独假设与对照，不混入本轮主修复。
4. 单平面诊断成功、共享三层失败：检查generator梯度、跨层梯度冲突与q高度/latent高度重复依赖。
5. 以上定位仍说明decoder拟合不足，才考虑坐标特征或网络结构变更，并单独给出来源与新假设。

不预先宣称“换激活、扩大网络、增加点数、加Seam、增加训练步数”能够解决本次条带。
